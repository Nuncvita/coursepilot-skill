# Capability Specification

## 定位

CoursePilot 是一个面向课程复习场景的 AI 能力层。它不是泛泛摘要课程材料，而是把多来源学习资料转化成更适合考试复习和学习规划的结构化输出系统。

## 核心能力定义（按优先级排序）

| 优先级 | 能力 | 说明 |
|---|---|---|
| P0 | 多资料融合 | 同时处理 PPT、教材、作业、真题和答疑，不依赖单一来源 |
| P0 | 高频考点识别 | 基于多资料重复证据识别高频章节、题型和考法，给出权重与优先级 |
| P0 | 个性化讲义生成 | 按用户风格调整表达，输出可直接复习、可直接做题的讲义 |
| P1 | 追问后讲义进化 | 判断追问价值并回写进讲义，而非一次性聊天 |
| P1 | 复习计划生成 | 根据剩余时间、目标分数和当前基础安排复习节奏 |
| P1 | 复习闭环输出 | 知识地图 → 讲义 → 练习 → 计划 → 冲刺包，各输出联动 |
| P1 | 学习风格选择与预览 | 支持多种粗分类风格选择、资料片段风格预览、混合风格和随时切换 |
| P2 | 练习与自测生成 | 优先覆盖高权重章节与薄弱点 |
| P2 | 最终冲刺包 | 压缩高频考点、必背公式、易错点和考前检查项 |

## 输入类型

### 必要输入

| 输入 | 说明 |
|---|---|
| 课程名称 | 标识复习范围 |
| 课程资料 | PPT 节选、教材节选、作业题、往年题中至少一种 |

### 增强输入（有则更好，无则降级处理）

| 输入 | 缺失时影响 |
|---|---|
| 剩余复习时间 | 无法生成精确复习计划，改为给出复习优先级 |
| 目标分数 | 无法调整深度和侧重，默认按"全面覆盖"处理 |
| 当前基础水平 | 无法识别薄弱点，默认按"基础偏弱"处理 |
| 学习风格偏好 | 无法个性化表达，先通过 5 个问题确认风格，用户跳过则使用默认高效复习型 |
| 历史答疑记录 | 跳过 Cross-reference 中答疑交叉环节 |
| 作业答案 | 练习题缺少参考口径 |

### 降级策略

当输入不完整时，CoursePilot 应：
1. 明确列出已收到什么、缺少什么
2. 说明哪些结论可靠、哪些只能做谨慎推断
3. 对缺失部分采用保守默认策略，不编造来源

## 输出类型

| 输出 | 对应 Workflow 步骤 | 说明 |
|---|---|---|
| 知识地图 | Extraction + Cross-reference | 章节结构、核心概念、关键公式、题型、优先级 |
| 考点权重表 | Weighting | 主题、证据、权重等级、原因、建议动作 |
| 个性化讲义 | Note Generation | 记忆区 + 正文 + 例题 + 易错点 + 速记 |
| 复习计划 | Planning | 按天拆分，含目标、内容、练习、自测和时间 |
| 练习题/自测 | Practice Generation | 代表题 + 模拟题 + 自测任务 |
| 易错点清单 | Note Generation + Follow-up | 常错原因 + 快速纠正 + 考试提醒 |
| 最终冲刺包 | Final Pack | Top 考点 + 必背公式 + 易错点 + 考前安排 |
| 追问补充内容 | Note Update | 回答 + 讲义增补 + 更新位置 + 新增易错提醒 |

所有输出共享同一口径和来源依据，不应出现自相矛盾。

## 关键能力详解

### 1. 多资料融合

- 不把课程学习理解成单文档总结
- 同时考虑 PPT、教材、作业、真题和历史答疑
- 能处理资料重复、口径交叉和局部缺失
- 输出时标注"资料明确出现"和"根据资料推测"的区别

### 2. 高频考点识别

- 识别反复出现的概念、题型和简答口径
- 区分高频章节、常错点和高分值设计题
- 权重应有资料证据支撑，不能凭主观猜测
- 支持生成考点权重与推荐复习顺序

### 3. 个性化讲解

- 根据用户风格调整讲义表达方式
- 保留"先讲人话，再讲公式，再讲考试怎么考"的结构
- 支持例题、对比表、易错点和速记区
- 难点拆成"是什么、为什么、怎么算、怎么考"

### 4. 追问后讲义进化

- 不把追问结果当作一次性聊天输出
- 判断追问是否属于：高频卡点、典型简答口径、易错点、适合加入对比表的内容
- 支持把补充内容加入正文、记忆区、易错点或快判口令
- 回写时不破坏原有讲义结构

### 5. 学习计划生成

- 根据剩余时间、目标分数和当前基础安排复习节奏
- 支持生成 3 天、5 天、7 天等不同长度的计划
- 每日任务应具备可执行性、自测标准和时间预估
- 计划应体现考点权重，高优先级章节优先安排

### 7. 学习风格选择与预览

- 用户可选择默认风格或其他粗分类风格（共 7 种可选风格）
- 如果用户未提供偏好，通过最多 5 个问题确认，用户可跳过直接使用默认
- 上传资料后可进行小片段风格预览（2-3 种风格各讲同一知识点 5-8 行）
- 支持混合风格（主风格 + 指定区段使用辅助风格）
- 支持中途修改风格（用户随时说"切换为 XX 风格"或"这部分用 XX 风格重讲"）
- 如果用户跳过所有选择，使用默认高效复习型，并在输出开头注明

### 8. 复习闭环输出

知识地图 → 考点权重 → 个性化讲义 → 练习与自测 → 复习计划 → 最终冲刺包，这些输出共同构成复习闭环，而不是孤立文档。

## 非目标

| 非目标 | 说明 |
|---|---|
| 不保证押题 | 考点权重基于历史证据分析，不是预测或承诺 |
| 不保证提分 | 输出定位为学习辅助，不是结果承诺工具 |
| 不替代课程学习 | 辅助复习，不能代替听课和理解过程 |
| 不帮助作弊 | 不生成作弊内容，不提供规避诚信要求的方案 |
| 不编造来源 | 无法确认时明确标注"不确定"或"待确认" |
| 不替代教师 | 不冒充老师或官方，不提供教学评估 |
| 不做实时答疑 | 专注结构化输出，不是通用聊天机器人 |
| 不存储用户数据 | 不持久保存用户提供的课程资料和个人信息 |
