# Sample Follow-up Update

## 场景说明

本示例展示 CoursePilot 的核心差异化能力：追问后讲义进化。普通总结器只会回答追问，CoursePilot 还会判断追问价值并回写进讲义。

## 追问中改变学习风格

用户可以在追问时要求使用不同风格重新讲解。例如：

"这部分用零基础补课型再讲一次。"

CoursePilot 应：
1. 切换到所要求的风格重新讲解
2. 将新风格的讲解内容补充进讲义
3. 保持原有风格版本，新版本作为该章节的风格变体
4. 记录风格变化："第 3 章讲义新增零基础补课型版本"

## 用户追问

"为什么很多题都说补零以后频谱更细了，但又说真实分辨率没有提高？这两句话不是矛盾吗？顺便把这点补进第 3 章讲义。"

## CoursePilot 回答

这两句话不矛盾，因为它们说的不是同一个层面：

- "频谱更细了"说的是频域采样点更密，画出来更平滑，更容易看到峰值落在哪附近。
- "真实分辨率没有提高"说的是你区分两个相近频率成分的本质能力，主要由观测时间决定，不会因为补零就凭空变强。

类比：补零是"把原来那条曲线画得更密"，不是"把望远镜换得更高级"。

## 讲义更新 Diff

### 更新前（第 3 章讲义节选）

```md
### 栅栏效应 / 频谱泄漏 / 谱间干扰

- 栅栏效应：DFT 只在离散频率点采样，峰值可能被漏掉
- 频谱泄漏：有限长截断导致频谱展宽
- 谱间干扰：不同频率成分互相干扰
```

### 更新后（第 3 章讲义节选）

```md
### 栅栏效应 / 频谱泄漏 / 谱间干扰

- 栅栏效应：DFT 只在离散频率点采样，峰值可能被漏掉
- 频谱泄漏：有限长截断导致频谱展宽
- 谱间干扰：不同频率成分互相干扰

### 补零的正确理解（追问补充）

- 补零会让 DFT 频域采样点变密，缓解栅栏效应的观感问题
- 补零不会改变原始观测时间，因此不真正提升频谱分辨率
- "看起来更平滑"或"峰值位置更容易估计"→ 补零有帮助
- "能否分开两个非常接近的频率分量"→ 不能只靠补零

一句话口令：补零改善采样细度，不提升真实分辨率。
```

## 更新位置

- 章节：第 3 章 谱分析与 DFT
- 插入点：`栅栏效应 / 频谱泄漏 / 谱间干扰` 之后
- 同步补入：本章易错点区 + 考前速记区

## 新增易错提醒

- 不要把"图更平滑"误写成"分辨率提高"
- 不要把"补零有帮助"泛化成"补零能解决所有谱分析问题"

## 为什么这能体现 CoursePilot 的差异

| 普通总结器 | CoursePilot |
|---|---|
| 只回答追问 | 回答 + 判断追问价值 |
| 回答后丢失 | 高价值内容回写进讲义 |
| 下次复习要重新问 | 下次复习直接看到补充内容 |
| 无更新位置说明 | 明确标注插入点和同步区域 |
