# ClawPro Demo Steps

## 1. 创建 CoursePilot

- 在 ClawPro 中创建一个新的 Skill / Agent
- 名称填写 `CoursePilot`

## 2. 粘贴 Prompt

- 将 `clawpro_prompt.md` 的内容粘贴到角色设定或系统提示区域

## 3. 输入 DSP 样例资料

- 使用 `samples/sample_input_dsp.md` 作为示例输入
- 说明输入包含课程名称、目标、学习风格和脱敏资料节选

## 4. 生成知识地图

- 让系统先输出课程知识地图
- 展示章节结构、核心概念、题型和复习顺序

## 5. 生成个性化讲义

- 继续要求生成个性化讲义
- 展示“先讲人话，再讲公式，再讲考试怎么考”的输出风格

## 6. 生成 7 天复习计划

- 输入时间约束
- 要求生成 7 天复习计划
- 展示每日目标、练习任务和自测标准

## 7. 用户追问

- 用 `sample_followup_update.md` 中的追问方式继续追问一个高频卡点

## 8. 系统补充讲义

- 展示系统不只是回答问题，还会给出“应补回讲义的内容”和“更新位置”

## 9. 输出最终冲刺包

- 要求生成考前冲刺包
- 展示高频考点、必背公式、易错点和最后检查清单

## 10. 总结价值

- 强调 `CoursePilot` 不是普通总结器
- 强调它的差异化在于：
  - 多资料融合
  - 考点权重分析
  - 个性化讲义
  - 追问后讲义进化
  - 复习闭环输出
