# Demo Script 3 to 5 Min

## 0:00-0:30 痛点

“课程复习最常见的问题不是没有资料，而是资料太散。课件、教材、作业、往年题和答疑记录分布在不同地方，普通 AI 虽然能总结，但常常不贴课程口径，也不会把追问沉淀回正式讲义。”

## 0:30-1:00 产品介绍

“CoursePilot 是一个面向教育场景的 AI 个性化课程复习 Skill。它接收多种课程资料，自动生成知识地图、考点权重、个性化讲义、复习计划和考前冲刺包，并支持用户追问后继续更新讲义。”

## 1:00-2:00 输入资料

展示：

- `samples/sample_input_dsp.md`

讲解重点：

- 输入不是单一文档，而是课件节选、教材节选、作业题、往年题和历史答疑
- 用户还提供学习目标、时间约束和学习风格
- 这使 Skill 可以做多资料融合和个性化适配

## 2:00-3:00 输出知识地图和讲义

展示：

- `samples/sample_output_knowledge_map.md`
- `samples/sample_output_personalized_notes.md`

讲解重点：

- 知识地图给出章节结构、核心概念、公式、题型和复习顺序
- 讲义不是只堆公式，而是“先讲人话，再讲公式，再讲考试怎么考，再给易错点和速记”
- 体现出考试导向与个性化风格

## 3:00-4:00 追问补充讲义

展示：

- `samples/sample_followup_update.md`

讲解重点：

- 普通总结器通常只回答这次问题
- `CoursePilot` 会判断解释是否值得沉淀
- 如果值得，就把它补回正式讲义、易错点和速记区

## 4:00-5:00 最终冲刺包和价值总结

展示：

- `samples/sample_output_study_plan.md`
- `samples/sample_output_final_crash_pack.md`

讲解重点：

- 7 天计划把复习拆成可执行任务
- 冲刺包把高频考点、必背公式、典型题型和最后检查项压缩到一页思路
- 总结差异点：多资料融合、考点权重分析、个性化学习风格、可进化讲义、复习闭环
