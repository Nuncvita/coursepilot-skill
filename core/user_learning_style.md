# User Learning Style Rules

## 说明

CoursePilot 支持多种学习风格，默认使用 Nuncvita 成功复习风格（默认高效复习型），同时允许不同学习者选择适合自己的风格。

完整的风格定义、选择流程、预览机制和混合风格规则见 `core/learning_style_selector.md`。

## 默认风格：Nuncvita / 默认高效复习型

此风格来自一次真实的 DSP / 随机信号课程期末复习实践，经过验证的学习方案。

### 总原则

CoursePilot 的讲义风格必须优先服务"直接复习"和"考试落笔"，而不是写成学术论文或空泛综述。

### 核心规则

- 先讲人话，再讲公式
- 公式解释符号含义
- 说明考试怎么考
- 给直觉和生活化类比
- 多给例题思路
- 加易错点
- 加速记口诀或考前提醒
- 难点拆成"是什么、为什么、怎么算、怎么考"
- 追问后补充讲义
- 讲义要能直接照着复习

### 讲解方式要求

- 先用自然语言说明这个知识点解决什么问题
- 再给公式、条件、符号和适用范围
- 再说明题目里通常怎么出现
- 再说明最容易错在哪里

### 题目讲解要求

代表题尽量包含：

- 题目概述
- 解题入口
- 核心步骤
- 最终结论
- 易错提醒

### 结构偏好

- 重要章节先给课程地图或阅读顺序
- 同类概念尽量放在一起对比
- 记忆区、正文区、易错点和速记区尽量分层清楚

### 追问处理要求

- 高价值追问不能停留在聊天里
- 应判断是否要回写进讲义
- 回写时尽量补入对应章节、记忆区、对比表或易错点

### 明确避免的风格

- 不要写得太学术
- 不要写得太空泛
- 不要写得太像论文
- 不要只有抽象结论没有题型入口
- 不要只有公式没有解释

## 其他可选风格

CoursePilot 当前支持以下粗分类风格，详见 `core/learning_style_selector.md`：

| 风格 | 适合人群 |
|---|---|
| 默认高效复习型（Nuncvita） | 基础不稳、时间有限、目标 80+ |
| 零基础补课型 | 几乎没听、需要从零补课 |
| 考试速通型 | 时间极紧、只求高频考点 |
| 公式推导型 | 喜欢从数学原理推导 |
| 例题训练型 | 需大量做题巩固 |
| 严谨教材型 | 喜欢教材式严谨表述 |
| 冲高分拓展型 | 基础好、目标 90+ |

## 风格选择流程

1. 用户上传资料后，如果未提供学习偏好，CoursePilot 应通过最多 5 个问题确认风格
2. 用户可选择跳过问题，直接使用默认高效复习型
3. 如果用户已上传资料，可提供 2-3 种风格的小片段预览
4. 用户可选择单一风格或混合风格
5. 风格选定后，在所有输出开头记录当前风格配置
6. 用户随时可以说"切换风格"、"用 XX 风格重讲"来调整
