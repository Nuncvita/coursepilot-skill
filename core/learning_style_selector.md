# Learning Style Selector

## 设计目标

CoursePilot 让不同学习者选择适合自己的讲义风格，而不是强迫所有用户使用同一种输出方式。

- 默认使用 Nuncvita 成功复习风格（默认高效复习型）
- 支持粗分类选择、风格预览、混合风格
- 所有风格和偏好可随时调整

## 默认风格

**名称**：默认高效复习型 / Nuncvita 风格

**来源**：来自一次真实的 DSP / 随机信号课程期末复习实践，经过验证的学习方案。

**适合谁**：基础不稳、课堂吸收不完整、时间有限（7 天左右）、目标 80+ 的学习者。

**讲解特点**：
- 先讲人话，再讲公式
- 每个公式解释符号、用途和适用条件
- 每个知识点讲清楚"考试怎么考"
- 多给直觉、类比和例题思路
- 加易错点和速记提醒
- 难点拆成"是什么、为什么、怎么算、怎么考"
- 最终产物能直接照着复习，不是论文也不是科普

## 粗分类风格

### A. 默认高效复习型 / Nuncvita 风格

- **适合谁**：基础不太稳，时间有限，目标 80+ 的复习者
- **讲解特点**：先讲人话再讲公式，重视考试导向、例题思路和易错点
- **输出重点**：知识地图 + 权重表 + 讲义 + 计划 + 冲刺包
- **不适合**：追求严格数学推导的学习者、已有坚实基础只缺刷题的学习者

### B. 零基础补课型

- **适合谁**：几乎没听过课，或基础非常薄弱，需要从零补课
- **讲解特点**：从最基础的概念讲起，每一步都解释，多用日常类比和图示描述，降低公式密度
- **输出重点**：概念解释 + 简单例题 + 逐级递进练习
- **不适合**：已有较好基础的学习者，会觉得节奏太慢

### C. 考试速通型

- **适合谁**：时间极紧（1-3 天），只求及格或快速过一遍高频考点
- **讲解特点**：极度压缩，只输出高频考点、必背公式和快判口诀，不展开推导，不提供长例题
- **输出重点**：Top N 考点 + 必背公式 + 易错点 + 一句话口令
- **不适合**：需要深入理解的学习者，会觉得信息太浓缩

### D. 公式推导型

- **适合谁**：喜欢从数学原理推出来的学习者，对"这公式怎么来的"有强烈需求
- **讲解特点**：给完整推导链，解释每一步的数学依据和物理意义，公式从定义开始推
- **输出重点**：推导链 + 符号系统 + 适用条件 + 典型推导题
- **不适合**：基础较弱或时间紧的学习者，推导细节会拖慢复习节奏

### E. 例题训练型

- **适合谁**：理论知识已大致理解，需要大量做题来巩固和暴露问题
- **讲解特点**：以例题为主线，每道题讲考点、入口、步骤、坑点和变型
- **输出重点**：分类例题 + 解题框架 + 易错点 + 自测题
- **不适合**：概念还不清楚的学习者，直接刷题效率低

### F. 严谨教材型

- **适合谁**：希望讲义风格接近正式教材，讲究定义严谨、层次清晰的学习者
- **讲解特点**：定义先行，定理证明，结构完整，术语规范，适合后续作为长期参考文档
- **输出重点**：章节体系 + 定义/定理/推论 + 标准例题 + 习题
- **不适合**：追求快速上手和口语化表达的学习者

### G. 冲高分拓展型

- **适合谁**：基础扎实、目标 90+，希望覆盖边缘考点和拓展内容
- **讲解特点**：在覆盖常规考点的基础上，补充冷门考点、综合题技巧和跨章节融合思路
- **输出重点**：全量考点 + 拓展专题 + 综合题 + 高分策略
- **不适合**：基础不稳固的学习者，应先把核心内容巩固好

## 学习偏好确认问题

如果用户未提供学习偏好，CoursePilot 应询问最多 5 个问题：

**问题 1：当前基础**
- A. 几乎没听，从零开始
- B. 听过一部分，但很多概念模糊
- C. 基本理解，但做题容易卡
- D. 基础牢固，主要想查漏补缺

**问题 2：目标分数**
- A. 及格就行（60 分）
- B. 中等偏上（70-80 分）
- C. 冲高分（80-90 分）
- D. 冲击满分（90+）

**问题 3：剩余时间**
- A. 1-3 天（极限冲刺）
- B. 4-7 天（短期复习）
- C. 1-3 周（常规复习）
- D. 1 个月以上（充分复习）

**问题 4：喜欢的讲解方式**
- A. 通俗易懂，先讲人话再讲公式
- B. 公式推导，从数学原理引出结论
- C. 以例题为主，通过做题来理解
- D. 严谨规范，像教材一样有条理

**问题 5：想要的输出形式**
- A. 完整系统（讲义 + 计划 + 练习 + 冲刺包全套）
- B. 只做讲义（不需要计划和练习）
- C. 只看考点（只关心考什么，不展开）
- D. 冲刺专用（只要最后压缩包）

用户可以直接选择"默认高效复习型"跳过所有问题。

## 风格预览机制

当用户上传课程资料后，如果还没确定学习风格，CoursePilot 可以进行风格预览：

1. 从用户上传的资料中选取一个小知识点（如某一节、某一个概念或某一道小题）
2. 用 2-3 种候选风格分别讲一小段（每种风格不超过 5-8 行）
3. 让用户看到差异后选择最合适的一种
4. 预览只展示短片段，不替代完整讲义生成
5. 如果没有上传资料，可以先用"占位示例"说明预览机制，等资料上传后再正式预览
6. 预览后让用户选择一种风格，或选择"混合风格"
7. 如果用户跳过预览，则使用默认高效复习型，并在输出开头注明

### 预览格式示例

知识点：第 3 章的"栅栏效应"概念

**风格 A：默认高效复习型**
> 栅栏效应就像是透过栅栏看风景——你只能看到栅栏缝隙处的东西，缝隙之间被挡住了。DFT 也是一样，只在离散频率点计算，如果真正的峰值正好落在两个计算点之间，你就看不到了。解决办法：补零可以让计算点更密，但别误以为分辨率提高了。

**风格 B：公式推导型**
> DFT 在频域对 DTFT 做 N 点均匀采样：X[k] = X(e^{jω})|_{ω=2πk/N}。当信号的真实频率落在两个采样点 2πk/N 和 2π(k+1)/N 之间时，DFT 无法直接观测到峰值位置，这就是栅栏效应的数学本质。补零通过增加 N 使采样网格更密，但不改变原始观测时长。

**风格 C：考试速通型**
> 栅栏效应 = DFT 只看离散点，峰值可能被漏掉。考试口诀：补零能让图更平滑，但不提升真实分辨率。选择题遇到"补零 → 分辨率提高"，直接排除。

## 混合风格机制

用户可以选择一种主风格，并对不同部分指定不同辅助风格。

### 混合风格示例

| 内容区段 | 使用风格 |
|---|---|
| 主体讲义（知识点讲解） | 默认高效复习型 |
| 难点解释（特别复杂的概念） | 零基础补课型 |
| 公式部分（推导和符号系统） | 公式推导型 |
| 练习部分（例题和自测） | 例题训练型 |
| 考前 24 小时冲刺 | 考试速通型 |

用户也可以简化为 2 风格混合，例如："主默认高效复习型，公式推导时用公式推导型"。

### 混合风格规则

- 主风格控制讲义的总体基调和结构
- 辅助风格只应用于指定的内容区段
- 切换风格时应在文中标注当前使用的风格
- 整体输出口径要保持一致，不同风格之间不能自相矛盾

## 默认降级规则

如果用户不选择任何风格（不回答问题、跳过预览）：

1. 使用默认高效复习型 / Nuncvita 风格
2. 在输出开头说明："当前使用默认高效复习型（Nuncvita 风格），你随时可以说'切换风格'来调整"
3. 用户在任何时候都可以说"换成 XX 风格"来切换

## 中途修改风格规则

- 用户可以在任何追问中说"这部分用 XX 风格再讲一次"
- CoursePilot 用新风格重新讲解，并记录风格变化
- 如果是讲义的对应章节，应将新风格的讲解补充进讲义，同时保留旧版本
- 整体讲义的主风格不变，只是该章节有多个风格版本供参考
