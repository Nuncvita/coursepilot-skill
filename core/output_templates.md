# Output Templates

## 概述

本文件定义 CoursePilot 的 10 个平台无关输出模板。每个模板说明使用场景、输出结构、必填字段、质量要求和简短示例。模板与 workflow 步骤的对应关系见 `workflow_core.md`。

## 输出组合策略

不同场景下应输出不同模板组合：

| 场景 | 推荐输出组合 |
|---|---|
| 场景 | 推荐输出组合 |
|---|---|
| 用户未提供风格偏好 | 风格确认（模板 9）→ 可选风格预览（模板 10）→ 再进入完整处理 |
| 首次完整处理 | 知识地图 + 权重表 + 讲义 + 计划 + 练习 + 冲刺包 |
| 用户只要求某部分 | 仅输出对应模板，但保持整体口径一致 |
| 追问时 | 追问回答 + 讲义更新（模板 8） |
| 考前最后阶段 | 冲刺包（模板 7） + 易错点清单（模板 6） |

## 1. 课程知识地图模板

> 对应 Workflow：Extraction + Cross-reference

### 使用场景

用于课程初步梳理、章节优先级判断和复习顺序规划。

### 输出结构

- 章节结构
- 核心概念
- 关键公式
- 常见题型
- 难度与优先级
- 推荐复习顺序

### 必填字段

- 课程名称
- 章节名称
- 核心概念
- 关键公式或方法
- 题型说明
- 优先级

### 质量要求

- 不能只列目录，要说明每章考什么
- 要体现知识点和题型的连接
- 要能支持后续生成讲义和计划
- 应标注优先级依据（来自哪份资料或哪种重复证据）

### 简短示例

```md
第 2 章：DTFT、Z 变换、ROC
- 核心概念：频率响应、收敛域、系统函数
- 常见题型：因果稳定判断、系统函数分析
- 优先级：A（PPT+真题+作业三源重复）
```

## 2. 考点权重表模板

> 对应 Workflow：Weighting

### 使用场景

用于从多资料中判断哪些章节和题型应该优先复习。

### 输出结构

- 章节/主题
- 资料来源证据
- 常见题型
- 权重等级
- 原因
- 建议动作

### 必填字段

- 主题名称
- 权重等级（A/B/C，A 为最高）
- 证据或依据（哪份资料、出现几次）
- 原因
- 建议复习动作

### 质量要求

- 权重应有依据，不能凭主观猜测
- 要区分高频主题和低频主题
- 最好能与复习计划直接联动
- 证据应标明来源类型（PPT/教材/真题/作业/答疑）

### 简短示例

```md
| 第 6 章 IIR 设计 | 真题+作业重复出现 | 设计题 | A | 分值高且流程易混 | 提前单独攻克 |
| 第 1 章 序列基础 | 仅教材提及 | 选择填空 | C | 基础分易拿 | 快速过一遍 |
```

## 3. 个性化讲义模板

> 对应 Workflow：Note Generation

### 使用场景

用于输出可直接复习、可直接做题的章节讲义。

### 输出结构

- 本章先看什么
- 记忆区
- 先讲人话
- 再讲公式
- 例题思路
- 这块考试怎么考
- 易错点
- 一句话速记

### 必填字段

- 章节名称
- 核心概念解释
- 公式与符号说明
- 考试导向说明
- 易错点

### 质量要求

- 先讲人话，再讲公式
- 公式要解释符号与适用条件
- 不能只有知识点，没有题型入口
- 每个重点知识点都要说明"考试怎么考"
- 易错点应具体，不要写成抽象建议

### 简短示例

```md
先讲人话：ROC 是看级数在哪些 z 上收敛。
再讲公式：X(z) = Σ x(n)z^(-n)，ROC 是使级数收敛的 z 的集合。
这块考试怎么考：常考因果、稳定和左右边序列判断。
易错点：ROC 包含单位圆 ≠ 因果。
```

## 4. 复习计划模板

> 对应 Workflow：Planning

### 使用场景

用于考试前短期冲刺规划。支持 3 天、5 天、7 天等不同长度。

### 输出结构

- Day 1 到 Day N
- 每天的目标
- 学习内容
- 练习任务
- 自测标准
- 预计时间

### 必填字段

- 日期或 Day 编号
- 复习目标
- 学习内容
- 练习任务
- 自测标准

### 质量要求

- 每日任务必须可执行
- 要体现章节优先级（高权重章节优先安排）
- 不能只写"复习第 X 章"，还要写怎么检验
- 自测标准应具体到"能独立复述 XX 流程"或"能解释 XX 和 XX 的区别"

### 简短示例

```md
Day 3
- 目标：主攻 IIR 设计
- 学习内容：双线性变换、预畸变、高通转低通
- 练习任务：完整走 1 道设计题步骤链
- 自测标准：能独立复述双线性变换流程
- 预计时间：3.5 小时
```

## 5. 模拟题模板

> 对应 Workflow：Practice Generation

### 使用场景

用于代表题讲解、自测训练和展示题型覆盖能力。

### 输出结构

- 题目
- 考查点
- 解题入口
- 分步解析
- 标准答案
- 易错点

### 必填字段

- 题目概述
- 考查点
- 解题入口
- 解析
- 易错点

### 质量要求

- 题目不能脱离课程口径
- 解析要有入口，不只给最后答案
- 避免大段复制原题原卷
- 应优先覆盖高权重章节

### 简短示例

```md
考查点：高通设计题
解题入口：先做预畸变，再转低通原型
易错点：忘记先做频率映射
```

## 6. 易错点清单模板

> 对应 Workflow：Note Generation（易错点汇总）+ Note Update（追问新增）

### 使用场景

用于考前集中回收常见混淆点和扣分点。

### 输出结构

- 主题
- 常错原因
- 快速纠正方式
- 考试提醒

### 必填字段

- 易错主题
- 错误原因
- 纠正方式
- 提醒语句

### 质量要求

- 易错点应具体，不要写成抽象建议
- 最好能直接对应某章或某题型
- 纠正方式应可快速执行，不需要再查资料

### 简短示例

```md
主题：补零与分辨率
常错原因：把图更平滑误认为分辨率提高
纠正方式：记住口令"补零改善采样细度，不提升真实分辨率"
提醒：看到"补零+分辨率"字样，先问自己"是采样密度还是分辨能力"
```

## 7. 最终冲刺包模板

> 对应 Workflow：Final Pack

### 使用场景

用于考试前最后一轮压缩复习。

### 输出结构

- 高频考点 Top N
- 必背公式
- 易错点
- 典型题型
- 考前 24 小时安排
- 最后检查清单

### 必填字段

- 高频主题
- 必背公式
- 易错提醒
- 最后检查项

### 质量要求

- 内容必须压缩，不重复长讲义
- 应体现最后阶段最该看的内容
- 不能写成新的大篇章讲义
- 检查清单应为可自问自答的判断题

### 简短示例

```md
一句话口令：补零改善采样细度，不提升真实分辨率。
最后检查：我能否区分 DTFT、Z 变换和频率响应？我能否独立复述双线性变换设计步骤？
```

## 8. 用户追问后讲义更新模板

> 对应 Workflow：Note Update

### 使用场景

用于把高价值追问正式沉淀回讲义，体现讲义进化能力。

### 输出结构

- 用户追问
- 回答摘要
- 建议新增到讲义的内容
- 更新位置
- 新增易错提醒

### 必填字段

- 追问内容
- 回答结论
- 讲义增补文本
- 更新位置（章节 + 具体插入点）

### 质量要求

- 不能只回答问题，还要说明如何沉淀回讲义
- 更新位置要清楚到章节和小节
- 要体现这是讲义进化，而不是一次性聊天
- 回写内容应与原有讲义风格一致

### 简短示例

```md
更新位置：第 3 章"栅栏效应/泄漏"之后
新增内容：补零的正确理解（4 条要点）
新增提醒：不要把"图更平滑"误写成"分辨率提高"
同步补入：本章易错点区和考前速记区
```

## 9. 学习风格确认模板

> 对应 Workflow：Style Preference Check

### 使用场景

用于用户首次输入资料但未提供学习偏好时，确认用户的学习风格、目标和剩余时间。

### 输出结构

- 当前基础
- 目标分数
- 剩余时间
- 候选讲解风格（推荐 1-2 种）
- 是否需要风格预览
- 默认推荐风格
- 用户最终选择

### 必填字段

- 当前基础确认
- 目标分数确认
- 剩余时间确认
- 确认的学习风格
- 是否使用混合风格

### 质量要求

- 最多 5 个问题，用户可直接选"默认高效复习型"跳过全部
- 如果用户跳过，应明确标注"当前使用默认高效复习型（Nuncvita 风格）"
- 问题应有选项，避免开放式长问卷
- 用户的选择应在后续输出开头记录

### 简短示例

```md
检测到你还没有设置学习风格，快速选择（最多 5 题，答"默认"跳过全部）：

1. 当前基础？A.几乎零基础 / B.部分模糊 / C.基本理解 / D.基础牢固 → B
2. 目标分数？A.60 / B.70-80 / C.80-90 / D.90+ → B
3. 剩余时间？A.1-3天 / B.4-7天 / C.1-3周 / D.1月+ → B

推荐：默认高效复习型 / Nuncvita 风格
是否接受？或输入"预览"看不同风格对比。
```

## 10. 风格预览模板

> 对应 Workflow：Style Preview

### 使用场景

用于用户上传资料后但未确定风格时，展示同一知识点在 2-3 种风格下的差异。

### 输出结构

- 选定的知识点（来自用户资料中的一小节/概念）
- 风格 A 预览片段
- 风格 B 预览片段
- 风格 C 预览片段（可选）
- 用户的选择引导

### 必填字段

- 知识点名称
- 至少 2 种风格的预览片段
- 每种风格标注风格名称

### 质量要求

- 预览只生成短片段（每种风格 5-8 行），不替代完整讲义
- 知识点应来自用户上传的资料内容，不能凭空编造
- 如果未上传资料，用占位示例说明机制，等资料上传后再正式预览
- 预览后引导用户选择，或询问是否需要混合风格

### 简短示例

```md
以下是同一个知识点"栅栏效应"在 3 种风格下的预览：

风格 A：默认高效复习型
栅栏效应就像透过栅栏看风景——你只能看到缝隙处的东西，
缝隙之间被挡住。DFT 只在离散频率点计算，如果真正的峰值
落在两个点之间你就看不到。解决办法是补零让计算点更密，
但记住：这不能真正提高分辨率。

风格 B：公式推导型
DFT 对 DTFT 做 N 点均匀采样：X[k] = X(e^{jω})|_{ω=2πk/N}。
当信号的真实频率落在两个采样点之间时，DFT 无法直接观测，
这就是栅栏效应的数学本质。补零增加 N 使网格更密，但不改
变观测时长 T。

风格 C：考试速通型
栅栏效应 = DFT 只看离散点，峰值可能漏掉。
考试口诀：补零让图更平滑，不提升真实分辨率。
选择题技巧：看到"补零 → 分辨率提高"直接排除。

你喜欢哪种？或选择混合风格。
```
